# taskflow
Taskfloww mintaalkalmazás RFT tantárgyból
## A projekt célja:
Egy egyszerű feladatkezelő minta projekt struktúrájának és verziókezelési folyamatainak gyakorlása. 
## Funkciók (tervezett)
- Feladatok létrehozása és listázása
- Státuszok kezelése a kanban táblán
Új funkció fejlesztése folyamatban
